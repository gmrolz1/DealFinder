## Read this first — how Patch 2 differs from Patch 1
These 11 are **newer / smaller developers** than the Patch-1 20, and that changes three things:

1. **Their egy.deals pages are profile + lead-capture pages, not listing pages (yet).** Each page has the developer's story, areas, FAQ, and the **live WhatsApp + Call CTAs that fire the conversion and rotate leads to your brokers** — so ads convert — but there is **no browsable unit inventory on them yet**. Landing-page depth is lower than Patch 1; expect a lower Quality Score until inventory is added. Add units to these developers and QS + conversion rate will rise.
2. **Several sell commercial / mixed-use, not apartments** (malls, business complexes, hotel-branded towers — e.g. EG Master's Aventura/Asgard malls, Eden's E One, Qurtuba's Nuzul Tower, DIG's Track malls). For those, keep the RSA hooks **generic** — "units · prices · installments · book now" — **not** "apartments, 10% down". Don't force the residential template onto a commercial project.
3. **Budget: start small and separate.** Do **NOT** pour these into the Patch-1 10,000 EGP/day pool — the high-inventory Patch-1 winners would starve them, and you want a clean read on each new developer's CPL first.
   - Recommended: a **second shared budget of ~2,000–3,000 EGP/day** across all 11, **Maximize Conversions** (portfolio). Once you see which developers convert, graduate the winners into the main budget.

## Structure per developer (same as Patch 1 §3)
Campaign `DEV — <Developer> — Search — Mobile` → one **Single-Theme Ad Group per project** (AR + EN) for the projects listed below + one **Brand+Area** ad group per language. Each ad group: only its own project's keywords (Exact + Phrase), a **DKI RSA** (headline 1 = `{KeyWord:<Project>}` pinned), shared negatives, sitelinks/callouts, call extension. Landing = the developer's page URL below (AR page for AR ad groups, EN for EN).

> The keyword lines are **seeds** — expand with Patch-1 §5 patterns. Simplify any long/bracketed project name to its core term (e.g. DIG's "Track Downtown Malls (…)" → keywords `Track Mall New Capital` / `مول تراك العاصمة`). Drop the auto-doubled area when a project name already contains it (e.g. "Aventura Mall New Capital" needs no second "New Capital").
